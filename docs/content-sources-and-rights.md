# 内容来源与版权边界

## 来源优先级

1. 教育部、教育考试机构和政府网站的正式文件。
2. 正式发布机构、官方出版社或权威教育研究机构。
3. 无官方在线全文时使用可靠数字图书馆、学术数据库、档案或正式影印本，并明确标注来源性质。

转载网页不能替代原始出处；搜索结果摘要不能作为正文证据。在线文本必须先确认篇目和版本，同文异版只能旁证作者、篇名等稳定事实。

## 仓库内容

公开仓库保存原创代码、方法文档、事实性元数据、来源链接、哈希和为核查所需的有限引文。不保存 Downloads 原始 PDF、本地历史汇编扫描件、整本 OCR 转录、Cloudflare 数据库导出、评论数据或 AI 对话内容。

源码与原创文档按根目录 `LICENSE` 授权。第三方文件、官方标准、出版物、扫描件和引文的权利仍归相应权利人；仓库中的元数据不构成对这些材料的再授权。

## 受控原页阅读

1902–2000 百年资料目录只向已登录的 BDFZ 统一用户开放**单条 bounded item** 的来源扫描页片段和逐页 OCR 候选。系统不发布整卷 PDF、公开对象地址、批量导出或整卷 OCR；响应不缓存、不索引，且每次读取都由 Worker 复核 item identity、来源 hash、连续物理页范围和发布包 hash。

原页用于核对候选文字，OCR 不是校定本，也不因可阅读而取得引文或语义断言资格。若 OCR 与图像冲突，以原页为准；正式引文仍必须通过项目既有的文档级与段落级双闸门。

## 移除与修正

若权利人或发布机构认为某项内容不应公开或不应继续受控展示，请通过 GitHub issue 提供资料的修正依据；涉及隐私、未公开内容或安全信息时使用 GitHub Security Advisory 私密渠道。确认后应优先关闭对应 reader item／pointer 或移除公开副本，同时保留必要的来源、哈希和审计记录。
